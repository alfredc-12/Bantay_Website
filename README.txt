BANTAY — local 3D website

Double-click index.html to open the website in Chrome or Edge.
No installation, internet connection or server is required. Keep the assets folder beside index.html.

The model fills the window. Choose a part in the small bottom-right menu to inspect it.
Use the Show labels checkbox above the menu to show or hide clickable numbered labels.
Hover or focus a numbered label to see the component name; click it to inspect the part.
Scroll down to separate the parts; scroll up to rebuild the box.
Drag the model to rotate. Hold Ctrl while scrolling, pinch, or use + / - to zoom.
Click a part in the model or choose its name in the menu to look closer.
Choose Whole device or press Escape in the viewer to see the entire unit.
With the viewer focused, arrow keys also separate and reassemble the parts.

The website uses the corrected Blender door and the same reversible assembly animation.
20 named components are included. The pump is a placeholder and its model remains to be confirmed.

The assets folder also contains the original GLB and a labels JSON file for future development.
The source folder contains the readable viewer code and build instructions.
